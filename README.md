# 📰 Projek UAS - Web Portal Berita

Aplikasi web portal berita dinamis yang dikembangkan menggunakan framework **Laravel** dan database **MariaDB/MySQL** sebagai pemenuhan Tugas Akhir Semester (UAS).

## 🚀 Fitur Utama
- **Halaman Publik / Pengunjung:**
  - Menampilkan daftar berita terbaru dan terpopuler.
  - Pencarian berita dan pengelompokan berdasarkan Kategori.
  - Halaman baca detail berita interaktif.
- **Halaman Admin (Dashboard):**
  - Autentikasi Admin (Login / Logout).
  - *CRUD* (Create, Read, Update, Delete) Data Artikel Berita.
  - Pengelolaan Kategori Berita.

## 🛠️ Tech Stack
- **Framework:** Laravel 13
- **Database:** MariaDB / MySQL (via Laragon)
- **Frontend / Styling:** Blade Template Engine & CSS framework
- **Version Control:** Git & GitHub
